# Лабораторная работа 6. Двумерные массивы

Решены все 10 задач из задания. Все задачи в одном файле `lab6.py`, при запуске программа спрашивает номер задачи. Матрица вводится по строкам, элементы через пробел. Номера строк и столбцов считаются с 1, как в задании.

Запуск:

```
python lab6.py
```

Задачи:

1. Вывод квадратной матрицы нечетного порядка по спирали против часовой стрелки, начиная с A1,1.
2. Сумма и произведение элементов K-й строки.
3. Номер столбца с наименьшим произведением элементов и само произведение.
4. Количество элементов больше среднего арифметического в каждом столбце.
5. Номер первого столбца, содержащего только нечетные числа (иначе 0).
6. Поменять местами минимальный и максимальный элемент в каждой строке.
7. Поменять местами столбцы с минимальным и максимальным элементом матрицы.
8. Поменять местами левую верхнюю и правую нижнюю четверти матрицы.
9. Упорядочить строки по возрастанию первых элементов.
10. Суммы диагоналей, параллельных главной, начиная с одноэлементной.

Пример работы:

```
Номер задачи (1-10, 0 - выход): 1

1. Вывод квадратной матрицы по спирали против часовой стрелки
Количество строк M = 3
Введите 3 строк, элементы через пробел:
1 2 3
4 5 6
7 8 9
1 4 7 8 9 6 3 2 5
```
