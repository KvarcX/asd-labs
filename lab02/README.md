# Лабораторная работа 2. Алгоритмы ветвления

Решены все 10 задач из задания. Все задачи в одном файле `lab2.py`, при запуске программа спрашивает номер задачи.

Запуск:

```
python lab2.py
```

Задачи:

1. Если A и B не равны, присвоить обеим переменным большее значение, иначе нули.
2. Сумма двух наибольших из трех чисел.
3. Какая из точек B и C ближе к точке A, и расстояние до нее.
4. Номер координатной четверти точки.
5. Описание целого числа («отрицательное четное число», «нулевое число» и т. д.).
6. Описание числа 1-999 («четное двузначное число» и т. д.).
7. Дата прописью по номеру дня и месяца («пятое января»).
8. Количество учебных заданий прописью с согласованием (10-40).
9. Трехзначное число прописью.
10. Название года по восточному календарю («год зеленой крысы»).

Пример работы:

```
Номер задачи (1-10, 0 - выход): 8

8. Количество учебных заданий прописью
n (10-40): 23
двадцать три учебных задания
```
