# Лабораторная работа 10. Бинарный поиск

Реализован бинарный поиск по словесному описанию из курса. Задаются левая и правая границы и берется средний элемент. Если он равен искомому, поиск закончен. Если он больше искомого, поиск продолжается в левой половине, если меньше - в правой. Если элемент не найден, функция возвращает -1. Перед поиском массив сортируется, на каждом шаге выводятся границы.

Запуск:

```
python lab10.py
```

Пример работы:

```
Элементы массива через пробел: 7 3 9 1 5 11 13
Отсортированный массив: [1, 3, 5, 7, 9, 11, 13]
Что ищем: 9
left = 0 right = 6 mid = 3 a[mid] = 7
left = 4 right = 6 mid = 5 a[mid] = 11
left = 4 right = 4 mid = 4 a[mid] = 9
Элемент найден, индекс 4
```
