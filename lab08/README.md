# Лабораторная работа 8. Сортировка вставками

Реализована сортировка вставками. Левая часть массива считается отсортированной. Каждый следующий элемент вставляется в нее на свое место, а большие элементы сдвигаются вправо. Состояние массива выводится после каждого шага.

Запуск:

```
python lab8.py
```

Пример работы:

```
Элементы массива через пробел: 5 1 4 2 8
Исходный массив: [5, 1, 4, 2, 8]
Шаг 1 (вставили 1): [1, 5, 4, 2, 8]
Шаг 2 (вставили 4): [1, 4, 5, 2, 8]
Шаг 3 (вставили 2): [1, 2, 4, 5, 8]
Шаг 4 (вставили 8): [1, 2, 4, 5, 8]
Отсортированный массив: [1, 2, 4, 5, 8]
```
