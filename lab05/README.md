# Лабораторная работа 5. Одномерные массивы

Решены все 10 задач из задания. Все задачи в одном файле `lab5.py`, при запуске программа спрашивает номер задачи.

Номера элементов считаются с 1, как в задании. Элементы массива вводятся в одну строку через пробел.

Запуск:

```
python lab5.py
```

Задачи:

1. Массив из N первых положительных нечетных чисел.
2. Первые N членов геометрической прогрессии.
3. Массив, где каждый следующий элемент равен сумме всех предыдущих.
4. Вывод элементов в порядке A1, AN, A2, AN-1, …
5. Сначала элементы с нечетными номерами по возрастанию, затем с четными по убыванию.
6. Среднее арифметическое элементов с номерами от K до L.
7. Проверка, образуют ли элементы арифметическую прогрессию.
8. Минимальный элемент среди элементов с четными номерами.
9. Номер последнего локального максимума.
10. Номера двух одинаковых элементов.

Пример работы:

```
Номер задачи (1-10, 0 - выход): 9

9. Номер последнего локального максимума
Элементы массива через пробел: 1 5 2 6 3 4 1
Номер: 6
```
