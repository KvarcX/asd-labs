# Лабораторная работа 12. Очередь

Реализован класс `Queue` (очередь по принципу FIFO: первый пришел, первый ушел) на основе списка. Операции:

- `enqueue` - добавить элемент в конец;
- `dequeue` - взять элемент из начала;
- `peek` - посмотреть первый элемент без удаления;
- `size` - размер очереди;
- `is_empty` - проверить, пуста ли очередь;
- `clear` - очистить очередь.

Работа с очередью идет через меню.

Запуск:

```
python lab12.py
```

Пример работы:

```
Очередь: ['А', 'Б', 'В']
1 - добавить элемент
2 - взять элемент из начала
3 - посмотреть первый элемент
4 - размер очереди
5 - проверить, пуста ли очередь
6 - очистить очередь
0 - выход
Выбор: 2
Взяли: А

Очередь: ['Б', 'В']
```
