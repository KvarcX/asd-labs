# Лабораторная работа 3. Циклические алгоритмы

Решены все 10 задач из задания. Все задачи в одном файле `lab3.py`, при запуске программа спрашивает номер задачи.

Запуск:

```
python lab3.py
```

Задачи:

1. Стоимость 0.1, 0.2, …, 1 кг конфет.
2. Произведение 1.1 · 1.2 · 1.3 · … (N сомножителей).
3. Квадрат числа через сумму нечетных чисел с выводом промежуточных сумм.
4. Сумма 1 + A + A² + … + Aᴺ одним циклом.
5. Значение 1 - A + A² - … ± Aᴺ без условного оператора.
6. Числа от A до B, каждое выводится столько раз, каково его значение.
7. Длина незанятой части отрезка A без умножения и деления.
8. Наименьшее K, при котором 1 + 2 + … + K ≥ N, и эта сумма.
9. Через сколько месяцев вклад 1000 руб. превысит 1100 руб. при P% в месяц.
10. НОД по алгоритму Евклида.

Пример работы:

```
Номер задачи (1-10, 0 - выход): 9

9. Через сколько месяцев вклад превысит 1100 руб.
P (0 < P < 25): 2
K = 5
S = 1104.08
```
