# Лабораторная работа 1. Линейные алгоритмы

Решены все 12 задач из задания. Все задачи в одном файле `lab1.py`, при запуске программа спрашивает номер задачи.

Запуск:

```
python lab1.py
```

Задачи:

1. Площадь и периметр прямоугольника по сторонам a и b.
2. Длина окружности по диаметру (π = 3.14).
3. Среднее арифметическое двух чисел.
4. Сумма, разность, произведение и частное квадратов двух чисел.
5. Сумма, разность, произведение и частное модулей двух чисел.
6. Расстояние между двумя точками.
7. Длины отрезков AC и BC и их сумма.
8. Произведение длин отрезков AC и BC.
9. Периметр и площадь прямоугольника по двум противоположным вершинам.
10. Периметр и площадь треугольника по координатам вершин (площадь по формуле Герона).
11. Значение функции y = 3x^6 - 6x^2 - 7.
12. Значение функции y = 4(x-3)^6 - 7(x-3)^3 + 2.
