# Лабораторная работа 4. Рекурсивные алгоритмы

Решены все 9 задач из задания. Все задачи в одном файле `lab4.py`, при запуске программа спрашивает номер задачи.

Запуск:

```
python lab4.py
```

## Оригинальное задание

Источник: [Задание к лабораторной работе 4.docx](https://online.mospolytech.ru/mod/assign/view.php?id=428845) (вложение в СДО).

**Задание к лабораторной работе 4**

1. Факториал числа: Напишите функцию, которая рекурсивно вычисляет факториал заданного числа n.
2. Числа Фибоначчи: Напишите функцию, которая рекурсивно вычисляет n-ое число Фибоначчи.
3. Возведение в степень: Напишите функцию, которая рекурсивно возводит число x в степень n.
4. Палиндром: Напишите функцию, которая рекурсивно проверяет, является ли заданная строка палиндромом.
5. Бинарный поиск: Напишите функцию, которая рекурсивно выполняет бинарный поиск заданного элемента в отсортированном массиве.
6. Обратный порядок слов: Напишите функцию, которая рекурсивно меняет порядок слов в заданной строке на обратный.
7. Разложение числа на сумму простых чисел: Напишите функцию, которая рекурсивно разлагает заданное число на сумму простых чисел.
8. Подсчет количества цифр в числе: Напишите функцию, которая рекурсивно подсчитывает количество цифр в заданном числе.
9. Напишите рекурсивное решение головоломки "Ханойская башня".

Пример работы:

```
Номер задачи (1-9, 0 - выход): 9

9. Ханойская башня
Количество дисков: 3
Диск 1 : A -> C
Диск 2 : A -> B
Диск 1 : C -> B
Диск 3 : A -> C
Диск 1 : B -> A
Диск 2 : B -> C
Диск 1 : A -> C
Всего ходов: 7
```
