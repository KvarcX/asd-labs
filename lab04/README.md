# Лабораторная работа 4. Рекурсивные алгоритмы

Решены все 9 задач из задания. Все задачи в одном файле `lab4.py`, при запуске программа спрашивает номер задачи.

Запуск:

```
python lab4.py
```

Задачи:

1. Факториал числа.
2. n-ое число Фибоначчи.
3. Возведение числа x в степень n.
4. Проверка строки на палиндром.
5. Бинарный поиск в отсортированном массиве.
6. Обратный порядок слов в строке.
7. Разложение числа на сумму простых чисел.
8. Количество цифр в числе.
9. Ханойская башня.

Пример работы:

```
Номер задачи (1-9, 0 - выход): 9

9. Ханойская башня
Количество дисков: 3
Диск 1 : A -> C
Диск 2 : A -> B
Диск 1 : C -> B
Диск 3 : A -> C
Диск 1 : B -> A
Диск 2 : B -> C
Диск 1 : A -> C
Всего ходов: 7
```
