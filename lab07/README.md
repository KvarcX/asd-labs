# Лабораторная работа 7. Сортировка пузырьком

Реализована сортировка пузырьком. Программа проходит по массиву, сравнивает соседние элементы и меняет их местами, если они стоят в неправильном порядке. После каждого прохода самый большой из оставшихся элементов оказывается в конце. Если за проход не было ни одного обмена, сортировка заканчивается раньше. Состояние массива выводится после каждого прохода.

Запуск:

```
python lab7.py
```

Пример работы:

```
Элементы массива через пробел: 5 1 4 2 8
Исходный массив: [5, 1, 4, 2, 8]
Проход 1 : [1, 4, 2, 5, 8]
Проход 2 : [1, 2, 4, 5, 8]
Проход 3 : [1, 2, 4, 5, 8]
Отсортированный массив: [1, 2, 4, 5, 8]
```
