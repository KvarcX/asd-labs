# Лабораторная работа 9. Сортировка выбором

Реализована сортировка выбором. На каждом шаге в неотсортированной части массива ищется минимальный элемент и меняется местами с первым элементом этой части. Состояние массива выводится после каждого шага.

Запуск:

```
python lab9.py
```

Пример работы:

```
Элементы массива через пробел: 64 25 12 22 11
Исходный массив: [64, 25, 12, 22, 11]
Шаг 1 (минимум 11): [11, 25, 12, 22, 64]
Шаг 2 (минимум 12): [11, 12, 25, 22, 64]
Шаг 3 (минимум 22): [11, 12, 22, 25, 64]
Шаг 4 (минимум 25): [11, 12, 22, 25, 64]
Отсортированный массив: [11, 12, 22, 25, 64]
```
