# Лабораторная работа 11. Работа с деревьями

Реализовано бинарное дерево поиска (класс `Node`, функция вставки `insert`) и его обходы:

- прямой (корень, левое поддерево, правое поддерево);
- симметричный (левое, корень, правое) - дает элементы по возрастанию;
- обратный (левое, правое, корень);
- в ширину (по уровням, с помощью очереди).

Дерево строится из введенных чисел и выводится «на боку»: правое поддерево сверху.

Запуск:

```
python lab11.py
```

Пример работы:

```
Числа для дерева через пробел: 8 3 10 1 6 14 4 7 13

Дерево:
        14
            13
    10
8
            7
        6
            4
    3
        1

Прямой обход: [8, 3, 1, 6, 4, 7, 10, 14, 13]
Симметричный обход: [1, 3, 4, 6, 7, 8, 10, 13, 14]
Обратный обход: [1, 4, 7, 6, 3, 13, 14, 10, 8]
Обход в ширину: [8, 3, 10, 1, 6, 14, 4, 7, 13]
```
